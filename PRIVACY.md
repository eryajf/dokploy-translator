# Privacy

Dokploy Translator performs translations locally in the browser.

- The extension stores site settings, custom translations and optional untranslated-text debug records in browser extension storage.
- It does not send page content, credentials, logs, API responses or translation data to a remote service.
- Host access is requested only for Dokploy origins entered and approved by the user.
- Debug records can be cleared from the options page and are never uploaded.
